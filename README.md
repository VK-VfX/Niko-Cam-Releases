# Niko's Cam releases

Public release channel for Niko's Cam. The app checks `version.json` on the
`never-spiral-apk-builds` branch for over-the-air updates.

- Latest APK: `never-spiral-apk-builds` branch, `niko-cam-release.apk`
- Each release replaces the previous one on that branch.
- Releases are signed with the Nikezvera release key.
